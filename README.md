# Free AI Reader (FAIR)

Офлайн-читалка для Windows: вставляешь ссылку на статью или текст — локальная ИИ-модель
сжимает его до нужного объёма, а приложение читает результат вслух.

Без облака: анализ идёт на своей машине (GGUF через llama.cpp), озвучка — Piper.
Интерфейс на русском и английском, лицензия GPL-3.0.

## Что умеет

- **Источник**: ссылка на статью (текст вытаскивается автоматически), вставленный текст, файл.
- **Сжатие**: готовые профили (10 %, 30 %, 50 %, 100 %) и свои уровни с собственным промтом.
- **Озвучка**: Piper (быстро, на процессоре), свой голос по образцу с микрофона,
  скорость речи, пауза между фрагментами, автоплей после анализа. Кнопка ⏯ ставит
  воспроизведение на паузу посреди фразы и продолжает с того же места; после конца —
  играет сначала.
- **Модель анализа**: любая GGUF; по умолчанию предлагается Gemma 4 E4B Q4_K_M (≈5 ГБ).
- **RU / EN** интерфейс, запоминается между запусками.
- Копирование результата, «Стоп» в любой момент, тема «Графит».

## Установка

1. Скачать `FAIR-Setup-<версия>.exe` из Releases.
2. Запустить, выбрать папку, при желании — ярлык на рабочем столе.
3. При первом запуске приложение само предложит **скачать модель Gemma (≈5 ГБ)** — с прогрессом
   и докачкой. Русские голоса **Ирина и Руслан** (а также английский `en_US-ljspeech-high`)
   уже входят в установщик и появляются в списке «Озвучка» сразу после установки.

Если голос удалить, приложение докачает его при следующем запуске. Добавить ещё голоса
можно кнопкой **⬇** рядом со списком «Озвучка» — там готовые (Irina, Ruslan, Amy, Alan,
Thorsten).

**Vox (нейроголос по образцу с микрофона)** — необязательное дополнение: при первом запуске
приложение предложит поставить его (переносимый Python + torch + VoxCPM, ≈1,5 ГБ загрузки,
~3 ГБ на диске). Ставится в `%LOCALAPPDATA%\FAIR\vox`, системный Python и права администратора
не нужны. Отказаться можно — тогда работает Piper.

Установка без прав администратора: по умолчанию ставится в профиль пользователя,
`%LOCALAPPDATA%\Programs\Free AI Reader`.

**Данные приложения** (настройки, модели, голоса) — `%LOCALAPPDATA%\FAIR`.
При удалении установщик спросит, удалять ли эту папку.

## Проверка установки без запуска окна

```
set FAIR_SELFCHECK=1
"%LOCALAPPDATA%\Programs\Free AI Reader\FAIR.exe"
```

Отчёт: `%TEMP%\fair_selfcheck.json` — импорты, наличие голоса, реальный синтез фразы.

## Сборка из исходников

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

rem приложение (из исходников)
.venv\Scripts\python modern_app_v2.py

rem установщик
.venv\Scripts\pyinstaller build_installer\fair.spec --noconfirm --distpath dist_installer
"%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" build_installer\fair.iss
```

В установщик входят голоса `en_US-ljspeech-high` (LJSpeech, public domain) и русские
`ru_RU-irina` / `ru_RU-ruslan` под CC BY-NC-SA (атрибуция в `THIRD-PARTY.md`,
коммерческое использование запрещено). Если собираешь без них — убери соответствующие
строки из `build_installer/fair.spec`.
