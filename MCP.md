# FAIR ↔ Hermes по MCP — подключение на любом компьютере

Приложение FAIR само поднимает локальный API (только 127.0.0.1:8756) при запуске окна.
Мост **fair_mcp.exe** (лежит рядом с FAIR.exe) переводит вызовы MCP в этот API —
Python на компьютере не нужен, всё внутри.

## Подключение к Hermes (один раз)

1. Установить FAIR этим установщиком и запустить приложение (окно). При старте рядом
   с данными появится `%LOCALAPPDATA%\FAIR\fair_api_endpoint.json` (порт и токен).
2. Установить/запустить Hermes Agent на этом же компьютере.
3. Зарегистрировать сервер (путь подставить свой — папка установки FAIR):
   ```
   hermes mcp add fair --command "C:\Users\<Имя>\AppData\Local\Programs\Free AI Reader\fair_mcp.exe"
   ```
   В интерактивном вопросе «Enable all 2 tools?» ответить `Y`.
4. Поднять таймаут вызова (озвучка статьи идёт минуты):
   ```
   hermes config set mcp_servers.fair.timeout 900
   ```
5. Перезапустить Hermes (или `/reload-mcp` в открытой сессии).

## Что появляется в Hermes

- `mcp_fair_fair_status` — состояние: движок (Vox/Piper), голос, модель ИИ, списки голосов.
- `mcp_fair_fair_speak` — текст **или ссылка на статью** + промпт обработки → FAIR
  обрабатывает нейросетью и озвучивает; возвращает абсолютный путь к wav
  (Hermes отдаёт его файлом `MEDIA:<путь>`).

Параметры `fair_speak`: `engine` = vox|piper, `voice`, `model`, `ratio` (сжать до доли
объёма), `gpu` (анализ на видеокарте), `speed`, `play` (играть в колонки FAIR).

## Замечания

- FAIR должен быть **запущен** при вызове; если закрыт — мост честно ответит
  «запустите FAIR», Гермес не подвиснет.
- Кнопка «Стоп» в окне FAIR отменяет и MCP-запрос.
- Vox-движок требует установки дополнения Vox (кнопка в окне FAIR, ~2.5 ГБ torch) —
  на новой машине это делается один раз до первой озвучки голосом Vox.
